# alexstengel personal site

Static site (HTML/CSS/JS, no build step). Open `index.html` or serve with `python3 -m http.server`.

- Headshot: replace the `.avatar` initials block in `index.html` with `<img src="assets/headshot.jpg" alt="Alex Stengel">`.
- AI Lab: update the placeholder cards in the `#ai` section as certifications/projects are completed.
- Deploy: push to a GitHub repo and enable GitHub Pages (Settings > Pages > Deploy from branch `main`, root).
